# 0 AI 原句提取与统计

在工具目录执行：

```powershell
.venv/Scripts/python.exe xhs.py analyze --input downloads/run1 --input downloads/run2 -o output/analysis
```

输入支持单个 `results.json`、`note.json`，或包含这些文件的归档目录；显式JSON文件也接受相同结构。
命令不启动浏览器、不需要登录、不发网络请求、不调用LLM、embedding、OCR或ASR。
采集、分析分别调用，分析不会触发补采或模型兜底。旧归档仅被读取，不修改。

## 规则与证据

规则版本 `human-query-1` 从标题和正文按句提取三类原句：求素材/原图/模板/音源、询问名称/是什么梗、询问用法或配文案。
保留原句中的梗名与标点；不改写、不推断目标梗ID。原文切片位置、上下文、归档路径、SHA-256和JSON pointer随每条结果保存。
平台标记为小红书，层级为 `real_expression`，`is_actual_search_log=false`。
模型生成和平台建议不混入此层。评论与搜索建议目前没有采集入口，不在本命令中补造。

这是明确句式的规则命中，不是对需求语义的全面识别。普通“分享表情包”不会只因含素材词就入选；
没有问句/求素材标志的真实需求可能漏掉。原句不匹配时不产生记录。
这些结果是人的原文需求线索，不是搜索量、用户真正提交的搜索日志或已确认梗名。

## 输出

| 文件 | 内容 |
| --- | --- |
| `queries.jsonl` | 原句、命中规则、版本、跨度、上下文、多份证据引用 |
| `queries.csv` | Excel可读的原句及来源索引 |
| `observations.jsonl` | 去重观察；原互动显示、解析值、近似标记、原观察时间与证据 |
| `notes.csv` | 每篇笔记一次的选中快照；规范公开URL、正文、作者、发布时间与互动值 |
| `stats.csv` | 每项互动的可解析值合计、已知/缺失/未解析/近似数量 |
| `summary.json` | 输入数、作品/观察数、重复数、原句数、命中规则分布、字段覆盖和输入完整性 |
| `inputs.json` | 输入路径和SHA-256 |
| `task.json`、`tasks/` | 分析执行状态及历史任务 |

CSV使用UTF-8 BOM，并保护公式前缀。导出的是规范来源链接，不输出访问令牌或媒体临时直链。

## 去重、时间与统计口径

- 作品按稳定note ID去重。同一作品、观察时间与文本/计数等内容相同的快照只算一次观察，多份证据保留；缓存标志不会制造新观察。
- 原句按作品、字段、跨度、原文和规则版本去重。相同原句跨作品仍保留多个来源；`distinct_query_texts`额外统计不同原句文本数。
- 原观察时间缺失就保持null，今天分析的时间只写`recorded_at`。不从文件修改时间或发布时间补造观察时点。
- 同一作品多个快照取已知观察时间最新的一份参与总计，历史观察仍保留；同一时刻或全部未知时按排序后的输入路径、行序取第一份，不推断实际先后。未知时点快照不覆盖已知时点快照。
- 不把同一篇的多次累计点赞相加；计数下降照实保留。缺失或无法解析的数不填0，全缺失时合计为null。
- `1.2万`解析为12000并标近似，`100+`也是近似显示；`known_value_sum`是显示值解析后的合计，含近似项时不能当精确总数。原值在观察文件保留。
- `complete=false`的归档可以分析，但会计入`incomplete_input_files`。分析完成不代表原采集完整。选样来自传入归档，不能据此推断全站需求或热度。

此模块只做规则提取与描述统计，不创建meme定义、衍生归并、人工批准或公开入库记录。
